DuoBar 首个公开试用版。

电池与 Wi-Fi 合成一个圆形菜单栏图标，底部四项等大状态圆点支持排序和隐藏。状态变化时圆弧与点阵平滑跟随归位，Wi-Fi 保持正向；充电时圆环变绿并短促扫光，结束后停止刷新。设置底部提供小红书一键跳转、微信和邮箱复制，复制后在右侧显示绿色提示。

下载与安装：
- 推荐下载 DuoBar-0.1.2-universal.dmg，打开后把 DuoBar.app 拖进 Applications。
- ZIP 用户解压后将 DuoBar.app 移入应用程序文件夹。
- macOS 13+；包含 Apple Silicon 与 Intel。Apple Silicon 已实机验证，Intel 尚未真机验收。
- 当前未做 Developer ID 签名和 Apple 公证。首次打开可能需要在系统设置 → 隐私与安全性中选择“仍要打开”。
- 按住 ⌘ 拖动图标到控制中心左侧；首次定位、隐藏原生图标和系统授权需要用户设置。
- Wi-Fi 名称依赖定位授权。专注状态依赖系统共享，授权后的专注切换尚未完成实机验收。

应用没有 Dock 图标、账号、服务器或遥测。安装说明也包含在 DMG 中。
