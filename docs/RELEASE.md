# MyDuoBar 1.5.0

- 選單中的聲音改為原生子選單，往右展開：上方為目前輸出裝置與音量百分比，中間是可拖曳的音量滑桿，下方是帶喇叭圖示的靜音列，按整列即可切換。
- 滑桿自行繪製（系統滑桿在選單中會失去強調色），支援拖曳、捲動與 VoiceOver 調整；快速拖曳時只寫入最新的音量。
- 靜音時拉高音量自動解除靜音；音量為 0 時解除靜音會回到 25%；沒有靜音功能的裝置以音量歸零代替；無法調整音量的裝置停用控制項。
- 狀態讀取改用系統的虛擬主音量，選單顯示的百分比與滑桿一致。
- 耳機與專注拆成兩塊面板，中間放入原生的聲音項目；VPN 與靜音列共用同一種開關列元件。

# MyDuoBar 1.4.0

- 選單中的 VPN 改為原生子選單，列出系統登錄的每個 VPN（含 Tailscale、Surfshark 等 App 提供的 VPN），每列附開關，按整列即可連線或中斷。
- 切換時選單保持開啟並追蹤狀態最多 30 秒；macOS 拒絕要求時開啟「VPN 設定」；連不上時開關回到關閉。
- 以命令列啟動的 VPN、TUN 路由與系統代理無法由 macOS 切換，改以灰字提示。
- 選單內的開關改為自行繪製：原本系統開關在選單中一律顯示為灰色，Wi-Fi 開啟時看起來像關閉。
- 電池與耳機、聲音、專注拆成兩塊面板，中間放入原生的 VPN 項目。

# MyDuoBar 1.3.0

- 選單中的 Wi-Fi 改為原生子選單，像系統 Wi-Fi 選單一樣往右展開：Wi-Fi 開關、已知的網路、其他網路、Wi-Fi 設定。
- 按開放網路直接加入；有密碼的已知網路使用鑰匙圈密碼加入，macOS 可能先詢問授權；其他情況開啟「Wi-Fi 設定」。
- 打開選單時在背景掃描附近網路並保留 15 秒；子選單開著時，只有結果或 Wi-Fi 開關改變才重建，不會打斷正在瀏覽的巢狀選單。
- 設定視窗新增「圖示說明」，逐項說明外圈、綠色與黃色外圈、中間 Wi-Fi 圖形與底部圓點，圓點說明跟隨排列順序。
- 新增 Wi-Fi 網路分組與子選單結構測試。

# MyDuoBar 1.2.0

- 新增英文與日文介面，設定視窗可選擇「跟隨系統」、繁體中文、English、日本語，切換後立即生效。
- 定位與專注模式的系統權限提示提供三種語言，重新開啟 App 後套用。
- 移除設定視窗的「聯絡開發者」區塊，App 內不再包含任何外部網址，也不再寫入剪貼簿。
- 設定視窗依內容自動調整高度，避免不同語言的文字被截斷或留下空白。
- 新增設定視窗語言切換測試；測試改用固定的偏好設定網域，不再於系統偏好設定資料夾累積空檔。

# MyDuoBar 1.1.0

- 介面、系統權限說明與文件全部改為繁體中文（台灣用語）。
- 改以 macOS 27 SDK 編譯，最低支援 macOS 26.0。
- 改用 Swift 6 語言模式與嚴格併發檢查：系統狀態監控改為主執行緒隔離，背景佇列只做讀取並回傳值型別，所有系統回呼都明確切回主執行緒。
- 以新的字串解碼寫法取代 macOS 27 SDK 標示為棄用的 `String(cString:)`，並以 `NSApp.activate()` 取代已過時的 `activate(ignoringOtherApps:)`。
- 建置腳本會自動挑選與 SDK 相符的 Swift 編譯器；架構驗證改為比對架構清單，相容新版 `lipo`。

# MyDuoBar 1.0.0

以原專案 DuoBar 1.0.0 為基礎：

- App 名稱改為 MyDuoBar，Bundle ID 改為 `com.rex.myduobar`。
- 修正 Swift 6.2 工具鏈下兩個編譯錯誤。

## 原版 DuoBar 1.0.0 重點

開啟低耗電模式後，電池外環顯示系統黃色；即使同時接上電源，黃色仍優先。關閉低耗電模式後恢復接上電源的綠色或一般顏色。

外圈線寬由 1.9 pt 增加到 2.47 pt，圓點直徑由 2.6 pt 增加到 3.12 pt，電池外圈直徑維持 26 pt。中間 Wi-Fi 圖形放大為 1.15 倍，中心位置不變。按一下耳機列改為開啟藍牙設定。
