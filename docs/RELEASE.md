# DuoBar 0.1.5

电池圆弧采用 26 pt 外径、1.9 pt 线宽，底部四个状态圆点采用 2.6 pt 直径。图标画布预留完整旋转范围，避免圆点超出绘制边界。未开启状态保持清晰灰色。

Wi-Fi、电池、耳机、声音和专注状态行均可点击，右侧箭头提示设置入口。点击后菜单收起，并打开对应的系统设置。耳机进入声音输出；有线网络进入网络设置。VPN 行只显示连接状态，不显示跳转箭头。

状态切换与点击菜单时播放平滑旋转，连续状态更新不会从头重播。圆点顺序、显示偏好和本地状态读取沿用现有设置。
