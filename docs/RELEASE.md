# DuoBar 1.0.0

开启省电模式后，电池外环显示系统黄色；即使同时连接电源，黄色仍优先。退出省电模式后恢复接电绿色或普通颜色。系统电源模式通知会触发刷新，原有点击和状态变化动画保留。

外圈线宽由 1.9 pt 增至 2.47 pt（1.3 倍），圆点直径由 2.6 pt 增至 3.12 pt（1.2 倍）。电池外圈直径保持 26 pt。中间 Wi-Fi 图形放大到原来的 1.15 倍，中心位置不变。点击耳机行改为打开蓝牙设置，已在本机实际点击并回读“蓝牙”页面标题验证。

本机菜单栏缺失已定位到 macOS 的应用权限误关联：打开 ChatGPT 的菜单栏开关后，DuoBar 图标实际恢复。当前需保持该关联开关开启，系统关联记录尚未修改。

菜单栏权限恢复与点击详情菜单已通过本机实际操作验证。省电配色、接电状态恢复及已有状态与控件检查通过。系统设置中实际开启和关闭省电模式的完整往返尚未验收。
