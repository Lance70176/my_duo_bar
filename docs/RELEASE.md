DuoBar 0.1.3 公开试用版。

状态变化时，电量圆弧和四个圆点现在沿同一圆周同步转动，保持相对间距；Wi-Fi 保持正向。动画采用融合 GIF 的缓入缓出与轻微回弹节奏，约 1.2 秒完成。连续状态更新不会从头重播，电量变化也不会打断转动。

圆点直径与电量圆弧线宽统一加大，未开启圆点的灰色更清晰。

保留接电过渡后常绿、拔电平滑恢复、圆点排序与隐藏，以及设置底部的联系方式。

下载与安装：
- 下载 DuoBar-0.1.3-universal.dmg，把 DuoBar.app 拖进 Applications；更新前先退出旧版。
- macOS 13+，包含 Apple Silicon 与 Intel；Intel 尚未真机验收。
- 当前未使用 Developer ID 签名和 Apple 公证。首次打开可能需要在系统设置 → 隐私与安全性中选择“仍要打开”。
- 菜单栏位置、原生图标隐藏及系统授权由每台 Mac 分别设置。专注状态授权后的切换尚未完成实机验收。
