# MyDuoBar 1.8.0

- 選單中的電池改為原生子選單，往右展開：充電上限開關、macOS 提供的檔位（停在 80%、85%、90%、95%）與「電池設定…」。電池項目顯示電量與狀態，例如「87% · 已充電到 80% 上限」。
- 充電上限使用 macOS 內建的機制（「系統設定 → 電池」的充電上限），透過系統電池設定面板所用的 PowerUI 框架讀寫，不寫入 SMC、不需要管理員權限或常駐程式；設定由系統維持，結束 App 後仍有效。找不到框架或此 Mac 不支援時，開關顯示為停用並說明原因。
- 開關記住最後使用的檔位（預設 80%），在系統設定中改的檔位也會同步成為記住的檔位。
- 選單中的耳機改為藍牙：往右展開後列出與這台 Mac 配對過的每個藍牙裝置（AirPods、鍵盤、滑鼠、喇叭等），每列附開關，按整列即可連線或中斷，狀態依序顯示「連線中…」「已連線」；已連線的裝置排在前面，項目下方列出目前已連線的裝置名稱。
- 輸出裝置清單改放在聲音子選單：滑桿與靜音列下方列出所有輸出裝置與輸入裝置並標示目前使用中的裝置，按一下即可切換聲音輸出或麥克風，與系統聲音選單的配置一致。
- 藍牙使用 IOBluetooth 公開框架，只列出已配對的裝置並連線或中斷，不搜尋、不配對；第一次展開選單時 macOS 會詢問藍牙權限，Info.plist 加入三種語言的說明。藍牙子選單展開期間每 2 秒重新讀取一次；macOS 拒絕連線時開啟藍牙設定。
- 圖示底部的四個狀態圓點改為音量刻度：沿膠囊底部排列，每點代表 25%，靜音或音量為 0 時換成一條等寬的橫線，橫線與刻度都跟著弧線沿軌道滑行。可在設定中隱藏。
- 耳機連上時，圖示中間會以強調色短暫顯示耳機圖示（AirPods、Beats 用各自的圖示），約 2.2 秒後淡回 Wi-Fi。
- 新增充電上限的狀態字串（三種語言），以及以模擬服務驗證的電池、藍牙、輸入裝置子選單測試與音量刻度、靜音橫線的圖示測試。

# MyDuoBar 1.5.0

- 選單中的聲音改為原生子選單，往右展開：上方為目前輸出裝置與音量百分比，中間是可拖曳的音量滑桿，下方是帶喇叭圖示的靜音列，按整列即可切換。
- 滑桿自行繪製（系統滑桿在選單中會失去強調色），支援拖曳、捲動與 VoiceOver 調整；快速拖曳時只寫入最新的音量。
- 靜音時拉高音量自動解除靜音；音量為 0 時解除靜音會回到 25%；沒有靜音功能的裝置以音量歸零代替；無法調整音量的裝置停用控制項。
- 狀態讀取改用系統的虛擬主音量，選單顯示的百分比與滑桿一致。
- 耳機與專注拆成兩塊面板，中間放入原生的聲音項目；VPN 與靜音列共用同一種開關列元件。

外圈線寬由 1.9 pt 增加到 2.47 pt，圓點直徑由 2.6 pt 增加到 3.12 pt，電池外圈直徑維持 26 pt。中間 Wi-Fi 圖形放大為 1.15 倍，中心位置不變。按一下耳機列改為開啟藍牙設定。
